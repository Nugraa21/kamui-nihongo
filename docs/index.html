Setiap fitur dirancang dengan cermat untuk memaksimalkan proses belajar Anda, dari pemula hingga level lanjut.

Mode Hardcore

Sudden Death Boss Battle

Satu soal salah — skor kembali ke nol. Ratusan soal campuran N5+N4+N3 tanpa batas. Mode untuk yang benar-benar siap diuji.

JLPT N5·N4·N3

JLPT Exam Lockdown

Simulasi ujian JLPT resmi dengan timer dan lockdown mode. Latih kondisi ujian sebenarnya.

Stroke Lab

101 karakter dengan panduan urutan coretan yang benar. Dari hiragana, katakana, hingga kanji dasar.

Memory Match

Cocokkan kartu hiragana/katakana dengan romajinya secepat mungkin. Melatih memori visual dengan cara menyenangkan.

Kotoba Arena

Tantangan kosakata dengan sistem poin kompetitif. Uji penguasaan kata bahasa Jepang Anda secara dinamis.

Kamus Lengkap 500+ Kata

Kamus offline dengan 500+ entri terstruktur. Cari kosakata, kanji, dan frasa — tanpa koneksi internet. Selalu tersedia kapan pun dibutuhkan.
